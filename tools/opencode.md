<div align="center">
  <h1>OpenCode</h1>
  <h4>Open-Source Coding Agent</h4>
</div>

You can go [here](https://opencode.ai/) for more info on OpenCode

It's another one of those coding agents you can use for free. It can be used in the terminal, as a desktop app, and claimed to be used on any device.

On Linux you can run the following:

```sh
curl -fsSL https://opencode.ai/v2/install | bash
```

You might need to refresh the terminal to use it. Otherwise just run the following:

```sh
opencode
```

> [!NOTE]
> You can run the following for a web interface:
> ```sh
> opencode pair
> ```
> It will generate a hyperlink to navigate to in your browser.

You can use Ollama to host your models for local use and use opencode to utilize those models. 

> [!NOTE]
> Model compatibility and performance varies as you would probably have a very high end workstation card running the models for you.
